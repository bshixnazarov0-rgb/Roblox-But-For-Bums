# Bum Worlds - Godot 4 mobile prototype

This repository contains a small 3D prototype for a mobile-friendly world explorer.

## Features
- Third-person 3D movement
- Mobile joystick and drag-to-look controls
- 12 procedurally themed places
- Rune gates: activate runes before coins can be collected
- Coins and collectible skins
- Procedural obstacles, trees, rocks, particles, and varying palettes
- Automatic portrait/landscape mobile setup

## Run
1. Install Godot 4.3 or newer.
2. Open this folder through Godot's project manager.
3. Press F6 or run the project.

## Mobile controls
- **Left side:** move joystick
- **Right side:** drag to rotate the camera
- **Skin panel:** tap to select or purchase a skin
